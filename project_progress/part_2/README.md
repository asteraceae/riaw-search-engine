## Implementation

### Inverted index

The inverted index is built using the `all_terms` field from the
processed corpus (title, description, brand, category, sub_category,
product_details and seller terms).

For each term, the index stores the documents where the term appears
and its positions in each document (`index[term]` is a list of `[pid, positions]`).

### Conjunctive search

The search engine uses AND queries.

The query goes through the same `build_terms` as the documents, and only
documents containing all the processed query terms are retrieved.

### TF-IDF ranking

The retrieved documents are ranked using TF-IDF scores, as in Practice Session 1:
tf = term count / length of the document's count vector, idf = ln(N / df).
The query vector is built the same way, and the score is the dot product of
the query and document vectors.

Documents with higher scores appear first in the ranking.

## Test queries

Five queries were defined to test the search engine, combining popular
title terms (see section 3.3 of the notebook). We judged the top 30 results
of each query (Q4 only has 27 results) with these rules:

| id | query | relevant if |
|---|---|---|
| Q1 | `men cotton casual shirt` | a men's casual shirt in cotton or a cotton blend |
| Q2 | `women black round neck tshirt` | a women's round-neck t-shirt whose only colour is black |
| Q3 | `women cotton kurta` | a single women's kurta (not a kurta set) in cotton or a cotton blend |
| Q4 | `women blue denim jacket` | a women's jacket in denim (fabric or type) and in a shade of blue |
| Q5 | `men running shoes` | running shoes for men |

## Evaluation

The following evaluation metrics were implemented:

- Precision@K
- Recall@K
- Average Precision@K (divided by min(number of relevant documents, K))
- F1-score@K
- Mean Average Precision (MAP@K)
- Mean Reciprocal Rank (MRR@K)
- Normalized Discounted Cumulative Gain (NDCG@K, binary relevance; checked against `sklearn.metrics.ndcg_score`)

The evaluation was performed at K=5 and K=10 using:

1. The relevance judgments provided in `validation_labels.csv`
   for the two predefined queries.
2. Binary relevance labels for the top 30 retrieved documents
   of each of the five additional queries.

For each query, the ranking keeps the TF-IDF order of the judged documents
that the search engine returned. Judged relevant documents that were not
retrieved still count for recall.

For the additional queries, relevance labels were proposed with
AI assistance based on the available product information, following the rules above.

The evaluation is limited to the judged documents and does not
necessarily represent performance over the entire collection.

All evaluation results are displayed with three decimal places.
