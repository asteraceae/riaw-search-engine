## Implementation

### Inverted index

The inverted index is built using the `all_terms` field from the
processed corpus.

For each term, the index stores the document IDs where the term
appears and its frequency in each document.

### Conjunctive search

The search engine uses AND queries.

Only documents containing all the processed query terms are retrieved.

### TF-IDF ranking

The retrieved documents are ranked using TF-IDF scores.

The implementation uses logarithmic term frequency and smoothed
inverse document frequency.

Documents with higher scores appear first in the ranking.

## Test queries

Five queries were defined to test the search engine:

1. `men cotton casual shirt`
2. `women black round neck tshirt`
3. `men blue track pants`
4. `women printed kurta`
5. `women winter jacket`

## Evaluation

The following evaluation metrics were implemented:

- Precision@K
- Recall@K
- Average Precision@K
- F1-score@K
- Mean Average Precision (MAP)
- Mean Reciprocal Rank (MRR)
- Normalized Discounted Cumulative Gain (NDCG@K)

The evaluation was performed using:

1. The relevance judgments provided in `validation_labels.csv`
   for the two predefined queries.
2. Binary relevance labels for the top 20 retrieved documents
   of each of the five additional queries.

For the predefined queries, only judged documents were retained
when evaluating the rankings.

For the additional queries, relevance labels were proposed with
AI assistance based on the available product information.

The evaluation is limited to the judged documents and does not
necessarily represent performance over the entire collection.

All evaluation results are displayed with three decimal places.
